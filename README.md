# UTAF Website

The University of Tokyo Autonomy Forge - UTAF の公式サイト用Next.jsプロジェクトです。

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS

## Development

```bash
npm run dev
```

Open http://localhost:3000.

## Checks

```bash
npm run lint
npm run build
```

## Assets

- `public/images/utaf-logo.png`: provided UTAF logo
- `public/images/hero-robotics-lab.png`: hero robotics illustration
